Pet Image Classifier MLOps Project Guide

This guide helps you set up and run the project on a Linux machine with the same environment and workflow used in this repository.

This document is a full step-by-step setup and execution guide. You can copy the commands directly into a terminal.

Step 1: Install System Requirements

sudo apt update
sudo apt install -y python3 python3-venv python3-pip git docker.io docker-compose-plugin

Check Python and Docker:

python3 --version
docker --version
docker compose version

Step 2: Start Docker

sudo systemctl start docker
sudo systemctl enable docker

Step 3: Clone the Repository

git clone <your-repository-url>
cd pet-image-classifier-mlops

Step 4: Create a Virtual Environment

python3 -m venv .venv
source .venv/bin/activate

Step 5: Install Project Dependencies

python -m pip install --upgrade pip
pip install -r requirements.txt
If you see a NumPy/Torch compatibility issue, run this fix: 
pip install "numpy<2"

Step 6: Set Up Kaggle Credentials

Create the Kaggle config file:

mkdir -p ~/.kaggle
printf '%s\n' '{"username":"YOUR_KAGGLE_USERNAME","key":"YOUR_KAGGLE_KEY"}' > ~/.kaggle/kaggle.json
chmod 600 ~/.kaggle/kaggle.json

Replace YOUR_KAGGLE_USERNAME and YOUR_KAGGLE_KEY with your actual Kaggle account values.

Step 7: Download the Kaggle Dataset

python -m src.data.download_dataset \
  --dataset_name bhavikjikadara/dog-and-cat-classification-dataset \
  --target_dir data/raw

Or use the Python snippet:

import kagglehub
path = kagglehub.dataset_download("bhavikjikadara/dog-and-cat-classification-dataset")
print(path)

Step 8: Check Dataset Layout

The project expects data under data/raw with folders like:

data/
  raw/
    cats/
    dogs/

If not present, the preprocessing script can handle flat folders containing filenames with cat or dog in their names.

Step 9: Preprocess the Data

python -m src.data.preprocess --input_dir data/raw --output_dir data/processed --img_size 224

Step 10: Train the Model

python -m src.train --data_dir data/processed --save_dir models --epochs 3

The model artifact is stored as:

models/model.pt

Step 11: Run the Inference API

uvicorn src.inference.app:app --host 0.0.0.0 --port 8000

Health check:

curl http://localhost:8000/health

Step 12: Run the Docker Compose Service

docker compose build
docker compose up -d

Smoke test:

curl -f http://localhost:8000/health

Step 13: Run Tests

python -m pytest -q
Expected result: all tests should pass.

Step 14: Package for Submission

./scripts/package_artifacts.sh

This creates a ZIP artifact for project submission.

Step 15: Useful Notes

  • Keep the virtual environment active while working.
  • Do not commit your Kaggle API key to Git.
  • Make sure Docker is running before using docker compose.
  • Use the same Linux environment for consistent package behavior.
